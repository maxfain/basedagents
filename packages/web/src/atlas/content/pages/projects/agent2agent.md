# Agent2Agent

Protocol for communicating with agents and coordinating tasks, with Agent Cards for discovery.

Type: protocol · Evidence checked: 2026-11-13

**Evidence:** Published-source research; no runtime test, security audit or payment test was performed for this profile.

[Official/source URL](https://a2a-protocol.org/)

## Evidence scope

Agent Card includes identity, skills, interaction requirements and supported interfaces. Version must be recorded per interface; examples in docs are not evidence of a particular service version.

## What it does

A2A describes agent communication and task coordination. Agent Cards advertise identity, skills and interaction requirements. Store the card and each supported interface as evidence.

## What this does not establish

An advertised skill is a claim. It does not establish accepted work, service quality or compatibility with every A2A implementation.

## Implementation checklist

- Record the Agent Card location, interface version, authentication requirements, task states and a reproducible exchange.
