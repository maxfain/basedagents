# x402

HTTP payment protocol for charging clients for internet resources.

Type: protocol · Evidence checked: 2026-11-13

**Evidence:** Published-source research; no runtime test, security audit or payment test was performed for this profile.

[Official/source URL](https://x402.org/)

## Evidence scope

Official repository links community service directories and separates testnet/public facilitator from mainnet production choices.

## What it does

x402 describes payment for internet resources through an HTTP payment flow. Distinguish the resource seller, client, facilitator and discovery catalog.

## What this does not establish

Support for x402 is not proof of a specific network, asset, facilitator, price or refund policy. Testnet observations are different from production settlement.
