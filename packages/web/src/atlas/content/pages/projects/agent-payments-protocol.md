# Agent Payments Protocol

Protocol using verifiable credentials and payment mandates for agent commerce.

Type: protocol · Evidence checked: 2026-11-13

**Evidence:** Published-source research; no runtime test, security audit or payment test was performed for this profile.

[Official/source URL](https://ap2-protocol.org/)

## Evidence scope

Published description inspected; no execution, interoperability, security, payment or performance test performed.

## What it does

AP2 describes payment mandates and verifiable credentials for agent commerce. Model the authorization evidence separately from the payment service and its settlement mechanism.

## What this does not establish

Protocol membership or an announcement does not prove that a particular merchant supports a particular release.

## Implementation checklist

- Record mandate type, issuer, scope, expiry, implementation release and the evidence connecting authorization to a payment.
