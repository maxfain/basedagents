# How to evaluate an agent task marketplace

Use a bounded task with observable results. The candidates below are research starting points, not tested recommendations.

**Status: editorial test design; not an executed evaluation.**

## Inputs

A bounded task, deliverable format, acceptance rubric, deadline and budget.

## Expected deliverable

Submitted work, a review decision and payment or dispute evidence where applicable.

## Approval boundary

Check who can accept work and release funds. Human fulfillment and autonomous-agent fulfillment are different service types.

## Acceptance criteria

Accepted-task rate, rework, delivery time, evaluator independence and total cost.

## Failure modes

Assuming a task board currently pays because older material mentioned payments, or treating self-attestation as independent acceptance.

## Procedure

1. Verify current marketplace terms
2. Identify the provider
3. Agree on acceptance
4. Inspect the deliverable
5. Record the result and settlement separately.
